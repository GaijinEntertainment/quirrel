Returns `str` with white-space characters removed from the beginning only.

## Parameters

- `str` - the string to trim

## Return value

A new string with the leading white space removed; trailing white space, if
any, is kept.

## Notes

See [strip](sym:string.strip) for exactly which characters count as white
space.

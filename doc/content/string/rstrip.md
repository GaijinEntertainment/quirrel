Returns `str` with white-space characters removed from the end only.

## Parameters

- `str` - the string to trim

## Return value

A new string with the trailing white space removed; leading white space, if
any, is kept.

## Notes

See [strip](sym:string.strip) for exactly which characters count as white
space.

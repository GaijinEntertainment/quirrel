Returns the cosine of `x`, given in radians.

## Parameters

- `x` - angle in radians

## Return value

The cosine of `x`, always as a float.

## Notes

`x` is defined for any real number; there is no restricted domain to worry
about, unlike [asin](sym:math.asin) and [acos](sym:math.acos).

Reports whether any element equals `value`.

## Parameters

- `value` - the value to look for

## Return value

`true` if some element equals `value`, `false` otherwise.

## Notes

This is [contains](sym:types.Array.contains) registered under a second
name; the two are the same function and behave identically, including the
raw, identity-based equality described there.

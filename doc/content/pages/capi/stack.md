Moving values on the VM stack, and counting them.

These functions do not read or write values. Pushing a C value and reading one
back are on [Creating objects](page:capi/objects) and
[Manipulating objects](page:capi/manipulation). This page covers the shape of
the stack itself.

See [The stack](page:embedding/stack) for the index convention. Every function
here follows it.

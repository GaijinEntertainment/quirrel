Moving values around on the VM stack, and asking how many there are.

These do not read or write values: pushing a C value and reading one back are on
[Creating objects](page:capi/objects) and
[Manipulating objects](page:capi/manipulation). What is here is the shape of the
stack itself.

See [The stack](page:embedding/stack) for the index convention, which every one of
these follows.
